# UI/UX: หลักการและมาตรฐานระยะ (บังคับใช้ทุกหน้า)

**เจ้าของกำหนด: 2026-10-15** · ใช้กับทุกหน้าใน `src/routes/**` · ตรวจด้วยตา + `pnpm check` + `pnpm lint`

เป้าหมายในหนึ่งประโยค: **พื้นที่ที่มีแต่ส่วนสำคัญ โล่ง ชัดเจนในตัว — ไม่มี scroll ของหน้า**

## 1. กฎ 7 ข้อ (ห้ามละเมิด)

1. **หนึ่งหน้าจอ = หนึ่งหน้าที่** — รู้ทันทีว่าหน้านี้ทำอะไรได้ (ดูชื่อ + ปุ่มหลักปุ่มเดียว)
2. **ส่วนสำคัญต้องอยู่ในจอเดียว** — ถ้าต้องเลื่อนเพื่อหาปุ่มหลัก/ข้อมูลหลัก = ผิด ออกแบบใหม่
3. **ห้าม scroll ของหน้า** — เลื่อนได้เฉพาะ "กรอบ" ที่จำเป็น (`overflow-y-auto` + `scroll-slim` ในกรอบนั้น)
4. **อากาศสำคัญกว่าข้อมูล** — ระยะห่างขั้นต่ำ `gap-3`/`p-4` ระหว่างก้อน, `py-8` รอบเนื้อหาหลัก; อย่ายัดแถวให้แน่นเพื่อให้เห็นของเยอะ
5. **ตัวเลือก 2-7 แบบ = แผ่นไอคอน (ToggleGroup)** — ไม่ใช่ปุ่มยาว ๆ เรียงลง หรือ checkbox list ยาว
6. **ของที่ใช้ไม่บ่อยไปอยู่หลังการกระทำ** — ฟอร์มสร้าง/แก้เต็มรูป → `Sheet`/`Dialog` หรือหน้ารายละเอียด (`/[id]`) ไม่คาไว้บนหน้าแรกของหน้านั้น
7. **ของซ้ำต้องพับ** — ร่องรอย/ประวัติ/รายละเอียดรอง → `<details>` (เปิดอัตโนมัติเฉพาะตอนที่กำลังทำงาน)

## 2. มาตรฐานระยะ (ใช้ token เท่านั้น)

| ใช้ที่ไหน                 | ค่า                                                 |
| ------------------------- | --------------------------------------------------- |
| ระยะระหว่างก้อนเนื้อหา    | `gap-3` (แน่น) · `gap-6` (ระหว่างส่วน)              |
| ขอบในกรอบ                 | `p-4` (การ์ด) · `p-3` (ก้อนย่อย)                    |
| ระยะรอบเนื้อหาหลักของหน้า | `py-6` ถึง `py-8`                                   |
| ความกว้างคอลัมน์อ่านสบาย  | `--column-max` (ผู้ใช้เลือก 36–64rem)               |
| ความสูงแถวในรายการ        | ~`2.25rem` (ปุ่ม/แถวเดียว) — ไม่เกิน 2 บรรทัดต่อแถว |
| จำนวนก้อนสูงสุดต่อหน้าจอ  | **5** (เกินแล้วให้ย้ายไปหลังการกระทำ)               |

## 4. วิธีตรวจว่า "ผ่าน" (ทำได้จริง)

1. เปิดหน้าที่ความสูงจอ 100% → **ไม่เห็น scrollbar ของหน้า** (`document.scrollingElement.scrollHeight === clientHeight`)
2. ปุ่มหลักของหน้าโผล่ในจอแรกโดยไม่ต้องเลื่อน
3. นับก้อนเนื้อหาชั้นบนสุดของหน้า ≤ 5
4. ทุกระยะมาจาก token/utility ที่มีอยู่ ไม่มีค่าดิบ
5. `pnpm check` = 0 errors · `pnpm lint` ผ่าน · `pnpm test` ผ่าน

## 5. ที่มา

หลักการระยะ/การจัดกลุ่มใช้ชุดกฎดีไซน์ที่โหลดได้ในเครื่อง (`shadcn-svelte` → `rules/styling.md`, `composition.md`, `forms.md`: `gap-*` ไม่ใช้ `space-y-*`, ToggleGroup สำหรับตัวเลือก 2-7, Alert สำหรับ callout, Empty สำหรับสถานะว่าง, ScrollArea/Resizable สำหรับกรอบ) — แต่ยังคงใช้โทเค็นและคอมโพเนนต์ของโปรเจกต์เอง ไม่ได้ติดตั้ง shadcn-svelte
